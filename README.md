# cat-photo-app
A simple cat photo app built while learning HTML — freeCodeCamp project
## What I learned

- Semantic HTML elements: `main`, `section`, `figure`, `footer`
- Working with `img`, `alt`, and `figcaption`
- Creating links with the `a` element and `href`
- Lists with `ul`, `ol`, and `li`
- Text emphasis with `em` and `strong`
